# Waste Classification CNN

A deep learning project that classifies waste images into categories using a CNN.

## Files
- `WASTE CLASSIFICTION CNN.ipynb` — training notebook
- `gradio_app.py` — interactive demo
- `best_waste_classifier.keras` — trained model
- `class_names.json` — label mapping
- `classification_report.txt` — evaluation metrics
- `confusion_matrix.png` — confusion matrix plot

## Usage
    pip install -r requirements.txt
    python gradio_app.py
